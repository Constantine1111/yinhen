# 版本更新日志

> 按版本记录每个版本新增与修复的内容。当前版本发布后，新改动一律记入「下一版本（待发布）」小节，发版时定稿。

## v1.0.1（2026-10-14）

### 新增功能
1. **多选照片批量处理**：一次可选最多 20 张照片，逐张自动读取各自的拍摄参数，底部缩略图条快速切换查看，支持一键批量导出；照片缺少拍摄参数时可手动填写兜底
2. **尼康/索尼型号自动识别**：尼康 Z 系列显示为 ℤ（含 Z f 花体 𝒇、罗马数字 Mark 自动补全），索尼 a 系列显示为 α；支持中文品牌名（尼康/索尼），品牌名输入自动规范化
3. **导出默认原图**：导出尺寸默认按原图输出（最高 4096px），保留更多细节
4. **曝光参数统一分组**：焦距/光圈/快门/ISO 等合并为一张卡片，一键控制整组显隐
5. **UI 优化**：全部分段按钮等分布局；色板圆点加细边框；预设卡片等高对齐；皮肤选项平均分布

### 修复问题
1. **导出图片偶发全黑**：导出的水印图偶发照片区域黑图（水印文字正常），已修复

## v1.0.2（2026-10-14）

### 新增功能
1. **沉浸式新布局**：功能菜单栏改为底部悬浮胶囊条，采用系统沉浸光感材质（毛玻璃+光影），内容从胶囊下方穿过；页面沉浸延伸至状态栏/导航栏
2. **平滑转场动画**：横竖屏旋转、布局模式切换时界面组件平滑移动到新位置；点击底部页签时，菜单内容从胶囊点击位置展开
3. **折叠屏悬停适配**：折叠屏半折叠悬停时界面沿物理折痕分屏——横折痕上下分屏（上半屏浏览、下半屏菜单），竖折痕左右分屏（中间空出折痕带）；悬停时更换照片改用内嵌相册选择器（横折痕下半屏弹出、竖折痕在菜单栏内展开），不再跳转系统相册
4. **导航栏自适应**：菜单栏较窄时（如分栏拖至最窄），底部页签栏自动切换为可左右滑动的滚动模式，避免六项页签过挤

### 修复问题
1. **修复胶囊下方异常色块**：悬浮胶囊下方偶现阴影/色块矩形（材质默认投影与页签蒙层叠加所致），已修复
2. **细节优化**：菜单面板卡片与屏幕左右边缘保留出血边距，不再贴边

## v1.0.3（2026-10-15）

### 新增功能
1. **导出照片继承拍摄参数**：导出的水印照片完整继承原片的 EXIF 元数据——相机型号、镜头、光圈、快门、ISO、焦距、拍摄时间、位置等不再丢失；HDR 照片同样支持，批量导出每张继承各自原片参数
2. **悬浮页签文字明暗自适应**：底部胶囊页签文字颜色按下方内容明暗自动切换——深色内容衬底显示白字、浅色内容衬底显示黑字，任何背景下都清晰可读
3. **胶囊细描边**：浅色内容衬底时胶囊轮廓加 1px 细边框，与背景更有边界感（深衬白边、浅衬灰边）

### 修复问题
1. **修复面板底部空白死区**：菜单面板卡片背景延伸至屏幕物理底边，不再有约 28vp 的空白带
2. **胶囊条位置优化**：悬浮胶囊更贴近系统导航指示条，观感更沉稳

## v1.0.4（2026-10-19）

### 新增功能
1. **个人 Logo**：导入个人签名/徽标图片用作水印元素——自动生成黑白两版适配文字颜色，细长签名自动放大避免稀疏；两种用法一键切换：**替换品牌 Logo** 或 **替换署名**；样式页签内预览、更换、删除
2. **品牌手动指定**：品牌 Logo 支持下拉选择（默认按拍摄参数自动识别），识别不准时可手动指定
3. **分栏署名行**：分栏布局（标准白框/拍立得）署名独立成行，位于日期下方、与参数/日期列左对齐，分隔竖线覆盖三行
4. **预设默认开启署名**：应用预设样式时默认显示署名，无需手动开启
5. **导航胶囊滚动隐藏**：菜单面板上划时底部悬浮胶囊自动隐藏让出阅读空间，下滑或回到顶部自动恢复

### 修复问题
1. **胶片格式署名替换失效**：个人 Logo「替换署名」模式在胶片样式下仍显示 © 文字，已修复
2. **署名与日期间距过近**：居中布局下署名 Logo 紧贴日期文字，已增加间距
3. **悬浮胶囊位置偏高**：安全区高度被重复计算，带系统导航栏的设备上胶囊明显偏高，已修正

## v1.0.5（2026-10-20）

### 新增功能
1. **标签参数预设**：新增预设样式——曝光参数以细描边胶囊标签分段展示（焦距/光圈/快门/ISO 各自成签），样式页签内也可单独开关
2. **台历预设**：新增预设样式——大字日期台历排版，超大日期数字配右侧三行信息（年月红色强调、相机型号、拍摄参数）顶对齐；无边框照片满幅，底部白条放文字
3. **宽屏胶囊收窄**：分栏布局下底部悬浮胶囊条收窄至面板宽 69% 并居中，两侧留白更透气
4. **画幅比例**：导出页新增画幅比例选择——原图 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16 六档，按所选比例对照片做画幅式中心裁切（预览所见即所得，边框、水印与拍摄参数完整保留），默认原图不裁切
5. **会展参考图**：样式页「会展」预设参考图替换为真实导出效果图

### 修复问题
1. **保存按钮死区**：导航条可见时导出页「保存至图库」按钮大面积点击无效（悬浮胶囊内部 Swiper 消费触摸形成隐形死区），已修复；导出页同步禁用模糊背景，规避安全控件授权被系统静默拒绝

## v1.0.6（2026-11-02）

### 新增功能
1. **我的摄影档案（风格画像）**：每次导出成功后本地记录拍摄风格，统计相机/镜头 TOP3、焦段热力、光圈/快门/ISO 偏好、拍摄时段分布与连续记录天数；数据完全本地存储，不上传
2. **成就系统**：38 个成就分彩蛋/金/银/铜四档——品牌梗（尼康佬/索尼党/佳能人/富家子弟/德味少年）、御三家、器材梗、风格成就、时间成就（早鸟/夜猫子/凌晨四点的光）、行为成就（横幅党/方图控/原图至上）、入门成就（初见海面/熟手/一周之约/第一个标签/参数党）与金色招牌成就（千张老手/万张传说/全能摄影师/十项全能/品牌制霸/时间旅行者/水印大师/一年之约），集齐五家品牌梗解锁隐藏彩蛋「召唤神龙」
3. **蚀刻章成就徽章**：每个成就配一枚手绘蚀刻风六边形徽章，成就墙、成就详情、解锁弹窗统一展示；隐藏成就解锁前显示灰色六边形占位徽章与「???」
4. **成就解锁弹窗**：导出解锁成就时居中弹出正面弹窗（弹簧弹起 + 瀑布式浮现动画、3 秒自动收起、点击跳转档案页），一次解锁多个时合并为「XXX 等 N 个成就」一张卡、展示稀有度最高的成就徽章，金色成就带金色光效、彩蛋成就带虹光渐变；同一天最多弹 3 次，不阻塞正在进行的操作
5. **成就墙与进度**：成就墙按彩蛋→金→银→铜分组，已解锁显示彩色徽章与解锁时间，未解锁显示灰色徽章与实时进度（如「广角 3/5」），隐藏成就解锁前只显示「???」
6. **防作弊统计**：品牌/镜头/参数成就只认照片 EXIF 原生解析结果，手动输入的品牌型号一律不参与成就判定；导出失败不记录

### 优化调整
1. **导航精简为 5 页签**：样式｜参数｜版式｜导出｜我的——原「排版」「边框」合并为「版式」页签（页内分段切换），原「设置」「档案」合并为「我的」页签（页内分段：统计｜成就墙｜设置）
2. **品牌梗成就门槛下调**：尼康佬/索尼党/佳能人/富家子弟由累计 20 张下调至 5 张，与德味少年一致
